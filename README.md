# Bachelor’s Thesis — AI-Based Network Monitoring

Bachelor’s Thesis focused on intelligent network monitoring and traffic analysis using AI models for anomaly detection and traffic prediction.

## Project Overview

The project integrates:

- GNS3-based network topology
- Routers, switches and Docker containers
- SNMP monitoring
- Prometheus, Node Exporter and Pushgateway
- Grafana dashboards for infrastructure and traffic monitoring
- Isolation Forest model for anomaly detection
- LSTM model for traffic prediction
